# marketocat.com

Static site for Marketocat (Tailwind CSS v4). Pushing `main` to github.com/marketocat/marketocat.com deploys via Cloudflare Pages.

    npm install
    npm run build   # icons.mjs -> PNG icons from the original LinkedIn logo (marketocat-logo.jpg), build.mjs -> *.html, Tailwind -> assets/site.css

Edit content in `build.mjs` and styles in `src/input.css`, then commit the generated output.
