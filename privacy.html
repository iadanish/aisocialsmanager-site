Privacy Policy

Last updated: September 15, 2026

AISocialsManager is a self-hosted social media scheduling application. This policy describes how the application handles data.

Local operation

AISocialsManager runs on the user's own computer. All content, media files, captions, scheduling data, and social account connection tokens are stored locally on that computer. We do not operate any server that receives this data.

Data we do not collect

We do not collect, transmit, sell, or share personal information, social media credentials, content, or usage data. The application communicates directly and only with the social media platforms the user explicitly connects (for example, Facebook, Instagram, LinkedIn, YouTube, TikTok, and X) in order to publish content the user has scheduled.

Third-party platforms

When a user connects a social media account, authentication and publishing are governed by that platform's own terms and privacy policy. The application stores the resulting access tokens only on the user's local device and uses them solely to perform actions the user has explicitly requested.

Contact

For any questions about this policy, contact the application operator who provided you with this copy of the software.
